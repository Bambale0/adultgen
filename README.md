# AdultGen

AI video-generation platform for Telegram with a Mini App, multi-reference cinematic workflows, internal credits, partner payouts, moderation, and replaceable Telegram bot channels.

This repository is intentionally structured as a backend-first platform: Telegram bots are gateway clients, while users, balances, payments, projects, publications, and audit data live in the core backend.
